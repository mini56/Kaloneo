# Images supplémentaires fournies avec KALONÉO

Déposez ici les images à intégrer à la bibliothèque commune du logiciel.
Vous pouvez les envoyer **en vrac** : le classement par thèmes et le traitement
des doublons seront réalisés après dépôt.

Formats conseillés : PNG, JPG/JPEG, WebP et SVG.

Ce dossier est réservé aux nouvelles illustrations. Ne déplacez pas les
images techniques existantes des tests et ne modifiez pas les définitions V1.

**Important :** déposer les fichiers sur GitHub ne les intègre pas encore
à l'installateur. L'intégration et les contrôles seront réalisés séparément,
sans nouveau Build avant validation.
