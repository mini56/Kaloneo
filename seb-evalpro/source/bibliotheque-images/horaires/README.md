# Horloges de la bibliothèque KALONÉO

La bibliothèque comprend **48 nouvelles horloges PNG** nommées de `00H00.png` à `11H45.png`, par quarts d'heure. Les 48 anciennes images aux aiguilles incorrectes ont été retirées le 29/10/2026 ; elles restent récupérables dans l'historique Git.

Le catalogue `../catalogue-images.json` correspond désormais aux 48 fichiers réellement présents (empreintes Git SHA-1 et tailles).

Dans la V1 **Bon de transport** : fenêtre « Au départ » → `04H00.png` ; fenêtre « À l'arrivée » → `06H15.png`. Le candidat ne doit voir que les horloges et les titres génériques, **jamais les noms des fichiers ni les heures écrites**. Le barème sur 4, les cinq questions et le bilan sont conservés.

La vérification du rendu sur le PC candidat et les tests GitHub Actions restent à effectuer avant de publier un nouveau Setup.
